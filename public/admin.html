Con el botón Publicar en la web (arriba a la derecha) tus fotos, textos y precios quedan en línea para todos en ~1 minuto. Solo hay que conectar GitHub una vez en este computador:

  1. Abre GitHub → Nuevo token (fine-grained) ↗ con tu cuenta biocolombiaplus-max.
  2. Token name: Panel landing · Expiration: 1 año (o la máxima).
  3. Repository access: Only select repositories → cursosIA.
  4. Permissions → Repository permissions → Contents: Read and write.

Avanzado

Copia de seguridad

Exporta o importa toda la configuración. Si algún día no puedes publicar automáticamente, descarga site-config.js y súbelo a GitHub en public/assets/js/.

La contraseña se guarda cifrada (SHA-256) dentro de la configuración. Recuerda publicar el site-config.js para que aplique en el sitio en línea. Este acceso protege el panel de visitantes curiosos; para seguridad total protege también la URL /admin.html desde tu hosting.
